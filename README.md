🛠️ Minecraft Bedrock Achievement Fixer
一个纯前端运行的 Minecraft 基岩版存档成就限制解锁工具。无需上传文件到服务器，所有 NBT 解析与修改均在浏览器本地完成。
📌 主要功能
• 成就资格修复：一键清除 hasBeenLoadedInCreative、cheatsEnabled 等限制标记。
• 安全无损：仅修改成就与模式标记，不破坏建筑、背包及地图数据。
• 自动备份：导出时自动生成 .dat.bak 原始备份文件。
• 多格式支持：支持 .mcworld、.zip 以及单个 level.dat 文件。
• 双语支持：内置中/英文界面切换。
📖 使用方法
1. 导入你的 .mcworld 存档或 level.dat 文件。
2. 工具会自动诊断 NBT 状态并显示概览。
3. 点击“一键修复并导出”下载新存档。
4. 将新存档覆盖导入游戏即可。
⚠️ 注意事项
修复后重新进入游戏，切勿再次开启作弊或切换到创造模式，否则成就资格会被游戏重新锁定。
